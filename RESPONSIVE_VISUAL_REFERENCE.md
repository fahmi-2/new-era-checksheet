## Common Responsive Patterns Summary

```
┌─────────────────────────────────────────────────────────┐
│     RESPONSIVE PATTERN QUICK REFERENCE                │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  GRID:    3 cols → 2 cols → 1 col                      │
│  FLEX:    row → column                                  │
│  MODAL:   800px → 85vw → fullscreen                   │
│  FORM:    multi-col → single-col                      │
│  TABLE:   table format → card format                  │
│  BUTTONS: inline → full-width                         │
│  TEXT:    16px → 14px → 12px                          │
│  SPACE:   24px → 16px → 12px                          │
│  PADDING: 32px → 20px → 12px                          │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## Checklist for Responsive Implementation

```
✅ Breakpoints defined (4 tiers)
✅ Grid layouts responsive
✅ Forms flexible
✅ Tables converted to cards on mobile
✅ Modals fullscreen on mobile
✅ Touch targets minimum 44px
✅ Font sizes scale appropriately
✅ Padding/margins responsive
✅ No horizontal scroll (except tables)
✅ Buttons full-width on mobile
✅ Tested on actual devices
✅ Accessibility verified
```
